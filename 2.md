# Utilidades

Kali Linux reúne herramientas para analizar redes, revisar la seguridad de sistemas y realizar auditorías técnicas. También incluye utilidades para investigar incidentes y documentar resultados; deben utilizarse únicamente en equipos propios o con autorización.
